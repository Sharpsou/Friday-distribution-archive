# Limites de l’alpha

- Aucun binaire n’est publié publiquement pour le moment.
- Le Chat peut produire des erreurs ; ses réponses doivent être vérifiées.
- Google Calendar, l’accès distant et la sauvegarde portable ne sont pas livrés.
- Les notifications système ne sont pas garanties lorsque le Hub est arrêté.
- La lecture hors ligne suppose une première installation et synchronisation réussies.
- Une mise à jour reste une opération manuelle et contrôlée.
