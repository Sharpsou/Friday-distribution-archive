# Prérequis

- Windows 11 x64 pour le Hub.
- Un artefact Friday vérifié fourni séparément.
- PowerShell 5.1 ou PowerShell 7.
- Un emplacement programme, par défaut `D:\Friday`.
- Un emplacement de données protégé, par défaut `D:\FridayData`.
- Pour les téléphones : une adresse LAN stable et un certificat HTTPS approuvé.

Le runtime Node nécessaire est inclus dans l’artefact. Git, pnpm et TypeScript
ne sont pas requis pour utiliser Friday. Ollama, ses modèles et un navigateur
Chrome restent facultatifs selon les fonctions choisies.
