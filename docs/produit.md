# Découvrir Friday

Friday est un espace familial local-first. Un Hub installé sur Windows conserve
la base canonique et sert une PWA commune au PC et aux téléphones.

L’application couvre six usages : vue du jour, agenda, maison, budget, chat et
veille. Les opérations métier restent disponibles sans modèle d’IA. Ollama est
facultatif et fonctionne sur le même PC ; une indisponibilité du modèle ne doit
pas bloquer les tâches, les courses, les menus ou le budget.

Friday privilégie une origine HTTPS privée sur le réseau du foyer. Il ne demande
ni compte cloud ni adresse e-mail. Les fonctions Web facultatives sont signalées
et ne transforment pas le Hub en service exposé sur Internet.
