# Profils, hors ligne et synchronisation

Le propriétaire initialise le foyer puis ajoute le second adulte avec un code
temporaire. Chaque téléphone est appairé et peut être révoqué depuis les réglages.

Agenda, Maison et Budget sont partagés. Chat, Veille et les brouillons produits
par l’IA sont privés par profil. Les données locales du navigateur sont chiffrées.

Après une première synchronisation, la PWA conserve l’interface et les données
déjà reçues. Les écritures compatibles sont placées dans une outbox puis envoyées
au retour du réseau. Chat, collecte Web et génération IA nécessitent le Hub.
