# Support et sécurité

Les anomalies non sensibles peuvent être décrites dans les Issues GitHub avec la
version affichée et les étapes de reproduction. Ne joignez jamais base, journaux
privés, certificats, clé, jeton ou capture contenant des données familiales.

Une vulnérabilité doit être signalée par le canal privé de sécurité GitHub plutôt
que dans une issue publique. Le Hub ne doit pas être exposé directement à Internet.
