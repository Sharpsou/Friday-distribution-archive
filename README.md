# Friday — le quotidien familial, chez vous

Friday réunit les tâches, l’agenda, les courses, les menus, la réserve, le
budget, le Chat local et la veille personnelle dans une PWA utilisable sur PC,
Android et iPhone.

Vos données restent sur votre PC Windows. L’interface et les dernières données
synchronisées restent accessibles hors ligne sur les appareils déjà appairés.
Les fonctions d’IA peuvent utiliser Ollama localement ; seules les recherches
Web et les mises à jour demandées nécessitent Internet.

## Ce que Friday apporte

- **Aujourd’hui** rassemble ce qui mérite votre attention.
- **Agenda** organise tâches, rendez-vous et récurrences.
- **Maison** relie courses, menus, préparations, restes et réserve.
- **Budget** distingue réalisé, prévisionnel, enveloppes et provisions.
- **Chat** conserve des conversations privées par profil.
- **Veille** suit des sources et prépare des synthèses personnelles.

Friday est conçu pour un foyer de deux adultes : Agenda, Maison et Budget sont
partagés ; Chat et Veille restent privés par profil.
