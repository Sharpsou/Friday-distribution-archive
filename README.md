# Friday pour Windows

Statut documentaire : actif.

Ce dépôt représente le produit installable Friday. Les données du foyer ne
sont jamais stockées ici : elles restent dans `D:\FridayData`.

La version active est sélectionnée par `runtime/active.json`. Une installation
conserve aussi la version précédente pour permettre un retour arrière. Le
runtime fonctionne localement ; Internet n'est pas requis pour démarrer ou
utiliser les fonctions locales.

Cette préversion est **tous droits réservés**. Elle n'est pas ouverte à une
distribution externe tant qu'une licence et une signature de code n'ont pas
été décidées.

Voir [l'installation](docs/installation.md), le [guide utilisateur](docs/utilisation.md)
et la [politique de confidentialité locale](docs/confidentialite-locale.md).
